# 相态分类（phase_state_classification）—— Stage 17B Phase 2

**数据**：`_stage10/probe300`（T=1、R0=5、h=2、ε_pf=13、Lz=160、t≤300）+ 3 个 OFAT 对照（T=1、R0=5、Lz=80、t=200）。
**方法**：`tools/cg_analysis/m24/m24_transport.py`（按 OriginalID 对齐；z 周期；分层 wall h<1.0σ / inner 1.0–1.8σ / outer ≥1.8σ）。

## 1. 液态五特征逐条判定

| 特征 | 液态应有 | 实测（probe300） | 实测（OFAT 三例） | 判定 |
|---|---|---|---|---|
| **粒子扩散** | 高 | D_z = **0.0354** σ²/τ、D_r = 0.0061（自由粒子 D=1 ⇒ 慢 28×） | D_z = 0.050–0.060、D_r = 0.008–0.036 | ✅ 有扩散（慢但明确）|
| **邻居交换** | 高 | 300 τ 内 **X_end = 0.47**（τ_50 略超 300 τ） | **τ_50 = 160–185 τ**、X_end ≈ 0.51 | ✅ 邻居壳层可被替换 |
| **团簇融合可逆** | 可逆 | **团簇分裂事件 = 0**；最大团簇 262/266 | **分裂 = 0**；最大团簇 195–265/≈266 | ❌ **不可逆** |
| **结构记忆** | 弱 | 最大团簇持续增长到 ~100% 粒子 | 同 | ❌ 记忆强（单一聚集体）|
| **MSD 增长** | 正常扩散 | MSD–lag 近似线性（拟合区间 lag < 0.4 t_end）| 同 | ✅ 正常扩散（非亚扩散锁定）|

## 2. 分类结果

```
A 液态膜        : ❌（D_z 比自由粒子慢 28×，τ_50 ≈ 300 τ）
B 粘滞液体      : ✅ ← 当前模型（D_z ≈ 0.035–0.060 σ²/τ，MSD 线性，邻居交换可持续）
C 凝聚固体/玻璃 : ❌（无冻结：X_end ≈ 0.5；D 不为零；无亚扩散平台）
```

**⇒ 当前模型在单粒子层面已经是"粘滞液体（B）"，不是玻璃/固体。**

## 3. 但存在**尺度分离的不可逆性**（本轮最重要的定性发现）

| 层面 | 是否可逆 | 证据 |
|---|---|---|
| **单键 / 邻居壳层** | 可逆 | τ_50 = 160–185 τ，X_end ≈ 0.5 |
| **单个粒子位置** | 可逆 | D_z、D_r 均非零，MSD 线性 |
| **团簇（集体）** | **不可逆** | **0 次分裂**；团簇数单调下降 → 1；最大团簇 → ~100% |

⇒ 模型缺的不是"粒子能不能动"，而是**集体构型能不能回到更分散的状态**（`cluster_splits = 0` 在所有 4 例中成立）。

## 4. 各向异性（与机制设计直接相关）

| case | D_z | D_r | D_z/D_r | 说明 |
|---|---|---|---|---|
| probe300（ε_pf=13） | 0.0354 | 0.0061 | **5.8** | 径向被壁面钉住，轴向通畅 |
| ofat_ep11（ε_pf=11） | 0.0597 | 0.0360 | 1.66 | 弱壁：径向也较自由 |
| ofat_ep20（ε_pf=20） | 0.0502 | 0.0078 | 6.4 | 强壁：径向再慢 4.6×，**轴向几乎不变** |
| ofat_h4（h=4） | 0.0527 | 0.0172 | 3.1 | 厚膜：径向略自由 |

**关键**：ε_pf 11→20 使 D_r 降 4.6×，而 **D_z 只降 16%** ⇒ **"壁面钉扎径向、保留轴向输运"**。
⇒ 轴向输运通道**本来就通畅**——RP 型机制所需的"沿轴向重分布质量"**在动力学上并不受阻**。
