## 0. 三句话结论

1. **粗化不由扩散控制**：9 例真实生产数据的 Spearman 相关 **rate vs D_z：ρ = −0.04（p = 0.92）**；**rate vs τ_50：ρ = +0.19（p = 0.62）** ⇒ 无相关。
2. **P6 的慢粗化来自"亚稳双珠构型"**，不是几何隔离、也不是迁移率：`N_bead` 在 t = 300–600 稳定保持 **2**，间距在 **40–53σ** 小幅浮动，**largest_fraction 从 0.385 降到 0.302（没有任何珠子吃掉别人）**。
3. **当前体系没有自然选择长度**：D1 只在 1/9 例出现，且同一 R0=8 下 rate 相差 **60×**（P6 0.0010 vs P7 0.0625）⇒ 案例间变异远大于任何参数趋势。

## 2. Phase 2：相关性分析（回答"迁移越快→粗化越快？"）

```
rate    : [0.0073, 0.0043, 0.0182, 0.0020, 0.0113, 0.0010, 0.0625, 0.0042, 0.0113]
D_z     : [0.0452, 0.0182, 0.0539, 0.0494, 0.0320, 0.0405, 0.0391, 0.0345, 0.0320]
Spearman(rate, D_z)  : rho = -0.042 , p = 0.915   ← 无相关
Spearman(rate, tau50) : rho = +0.194 , p = 0.617   ← 无相关
```

**⇒ 粗化速率与粒子迁移能力之间不存在任何可辨相关性。**
反例最清楚的两对：**P2（D_z 最低 0.0182）却是最快的坍缩类别 D3**；**P7（D_z=0.0391）速率 0.0625 是全场最快，而同样 R0=8 的 P6（D_z=0.0405，几乎相同）速率 0.0010 是全场最慢（差 60×）**。

## 4. Phase 4：P6 为什么慢（逐项检查）

| 检查项 | 结果 | 说明 |
|---|---|---|
| 1. 珠子间距是否增大？ | **否（基本不变）** | mean_spacing 起 53.3σ → 末 40.0σ，中位 53.3σ；1000 t 内只在 40–53σ 浮动 |
| 2. 珠子是否被壁面层隔开？ | **否** | D_r=0.0107（并不最低，P2/P5 更低）；第一层未把珠子锁死 |
| 3. 是否存在稳定 N_bead 平台？ | **是** | t=100→3、**t=300→2、t=600→2**、t=1000→4 ⇒ 有 ~300 t 的双珠平台 |
| 4. 是否存在"珠子变大→运动变慢→融合减少"的负反馈？ | **部分成立但不是主因** | largest_fraction **从 0.385 降到 0.302**（没有单珠吞并），而 D_z 在 3 seeds 间仅 ±8% ⇒ 慢的主要来源是**构型亚稳**（两珠距离足够远、缺少把它们拉到一起的驱动力），而不是迁移率下降 |

**⇒ P6 的慢是"几何+构型"层面的亚稳性（R0=8 提供更大的周长与更远的珠间距），不是输运受限。**

## 5. 必须回答的四个问题

**1. 粗化是否由扩散控制？→ 不是。** Spearman ρ(rate, D_z) = −0.04（p=0.92）；最强反例：R0=8 的 P6 与 P7 迁移率几乎相同（0.0405 vs 0.0391）而速率相差 60×。
**2. P6 慢粗化的原因？→ 亚稳双珠构型**：N_bead 在 300–600 t 保持 2，间距稳定在 40–53σ，largest_fraction 由 0.385 降至 0.302（无单珠主导）⇒ 三个 seed 一致 ⇒ **不是偶然**，也不是壁面隔离或迁移率下降。
**3. 当前体系有没有自然选择长度？→ 没有。** 依据：① D1 只占 1/9；② 同参数带内速率相差 60×；③ 幅度最大者（P7）与最慢者（P6）R0 相同 ⇒ 不存在能把尺度"钉住"的内在机制（与 Stage 17/17B 的结论一致）。
**4. 需要添加哪一种机制？→ 尺度选择（k 依赖）机制。**
优先级与位置：在 **P6 带（R0=8, h=2.5, ε_pf=15, Lz=160）** 上加入
* **B′ 长程耦合**（SALR 型，排斥程 ξ ≈ 1–3 (R0+h)），或
* **B″ 有限波长核**（配对核的傅里叶变换在 k* 处有极小）；
验收仍为三检验：`L_bead/L_spec` 出现平台、出现持续 ≥200 t 的 `CV_spacing ≤ 0.35` 且 `largest_fraction ≤ 0.45` 窗口、平台尺度随 R0 单调变化。
**不要**先改 α（Stage 17B 已证键交换充足）、也不要先加守恒约束（P6 的轴向输运 D_z=0.0405 属高位）。
