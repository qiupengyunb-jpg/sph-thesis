## 4. 线性窗口判定（§七、§九）

固定算法：连续帧中 `SNR>3`，取最长连续段，段内最大化 `ln A_m` 的 R²，要求 ≥8 点。

| mode | dynamic SNR>3 持续窗口 | R²>0.8 的线性窗 | injected 是否明显高于 control | 判定 |
|---|---|---|---|---|
| m=2 | **无**（仅 1–2 帧） | **无** | 否（中位比 0.91） | **FAIL** |
| m=3 | **无** | **无** | 否（0.98） | **FAIL** |
| m=4 | **无** | **无** | 否（0.50） | **FAIL** |

**⇒ NO SEPARABLE LINEAR WINDOW（三个模一致）。不报告 ω（按 §七 要求）。**

§九 三判据：A（SNR>3 持续）✗、B（R²>0.8 窗口）✗、C（injected ≫ control）✗ ⇒ **Stage 8B = FAIL**。

## 5. 机制判读（只写数据支持的）

* **不是重建问题**：Stage 8A 已证明 Method D 把静态底噪降到 0.0063σ、恢复误差 ≤6.3%。
* **不是 frame-0 注入质量问题**：本轮的 frame-0 恢复误差 3.6–6.3%、纯度 1.000。
* **不是 packing 问题**：Stage 7 已证明提高 packing 只降低"整体弛豫幅度"，不降低模式内容。
* **是"确定性初始弛豫"本身**：t=0 的晶格远离相互作用平衡位置，弛豫在 **0.2–0.4 t** 内把**与注入同量级（≈0.02–0.03σ）**的低模内容注入所有模（含 A=0 对照），
  并与注入信号一起在 ~0.4 t 后**同步衰减**（T=0 noise-off 下体系随后冻结）。
  ⇒ 注入信号从一开始就**不是主导项**，无法形成"signal ≫ background"的可分离窗口。

## 6. 最终回答（§十二）

**A. Method D 下是否出现 dynamic SNR>3 的持续窗口？→ 否。** 仅 1–2 帧（t≤0.2），中位 SNR 0.50–0.98。
**B. 是否存在 R²>0.8 的线性增长窗口？→ 否。**
**C. injected growth 是否明显高于 A=0 control？→ 否。** 中位比值 0.91 / 0.98 / 0.50，且注入从一开始就在**衰减**。
**D. m=2/3/4 中是否至少有一个"可分离线性响应候选"？→ 没有。**
**E. 下一步 → FAIL 分支：停止当前单模 RP 路线**，回主线重新评估模型动力学（不做 reconstruction / packing / temperature / A / m 的继续调整）。
