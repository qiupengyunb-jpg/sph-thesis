## 2. 有没有"保持物理不变、只提高分辨率"的能力？（§二重点、§五）

**没有。** 原因是一条闭环约束：

```
σ 同时是：粒子尺寸(WCA) + Morse 作用尺度 + 壁面作用尺度 + 几何单位
d 由 σ 与 φ 唯一决定：d = σ √((π/4)/(0.5√3 φ))
φ 有硬上限：φ < 0.72（= WCA 密堆极限，solver 直接拒绝 ≥0.72）
⇒ 给定 σ，最小可能 d ≈ 1.1223σ（φ→0.72），即 d/σ 只能在 [1.10, 1.20] 内变动
⇒ 层数 rows = ⌊(h−0.5σ)/dr⌋ + 1，在 h=2σ 下**只能取 2 或 3 层**
```

要在**不改变物理问题**（同一 R0、同一物理膜厚、同一 Morse/WCA/壁面作用尺度、同一无量纲比值）下把 2 层变成 4–8 层，唯一途径是**减小 σ**；但 σ 同时定义了所有物理作用尺度，减小 σ 等于**换了一套相互作用模型**（WCA 核、Morse 井、壁面井都随之变窄），不是纯分辨率细化。

⇒ **结论（§五 指定措辞）：`CURRENT MODEL HAS NO CLEAN RESOLUTION PARAMETER`。**

## 3. Scheme E 的分辨率依赖（§六）

离散能量：`F_E = (λ/2)V0² Σ_{i<j} J_ij K̃_ij (ρ_i−ρ_j)²`，`K̃ = c·W`，`c = 144/(5h_ρ²)`。

| 量 | 若把粒子间距减半（假设可以） | 现状 |
|---|---|---|
| `V0` | 应变为**实际格胞面积** `(√3/2)d²`（减 4 倍） | **取固定常数** `1/ρ_ref = 1/0.88 = 1.1364`，与格距无关 |
| `ρ_i = Σ_j W` | 数密度定义，与格距自洽 | 同 |
| `h_ρ` | 必须**保持物理值 2.8σ 不变**（否则 kernel 尺度变了） | 固定 ✓ |
| `c = 144/(5h_ρ²)` | **不随格距变化** ✓ | 固定 ✓ |
| `λ` | 若 `V0` 与 `ρ` 自洽，**无需重标定** | 见下"但" |

**但当前实现里 `V0` 与膜的实际数密度不匹配**，因此**有效界面强度依赖离散化**：

```
膜的数密度 n0 = φ/(π σ²/4)
  φ=0.63 → n0 = 0.802 σ⁻²  ⇒ V0·n0 = 0.911 ⇒ λ_eff = λ(V0 n0)² = 9.96   (−17%)
  φ=0.70 → n0 = 0.892 σ⁻²  ⇒ V0·n0 = 1.013 ⇒ λ_eff = 12.3                (+2.5%)
```

⇒ ① **λ=12 只在 ρ_ref=0.88 与实际密度一致时才成立**；② 这解释了 Stage 7 的"提高 packing 不是有效分辨率提升"——它同时把 λ_eff 改了 ≈24%；
③ **要做真正的 resolution ladder，必须先把 `V0` 改为实际格胞面积（或把 `ρ_ref` 改成实际 n0）**，否则任何"收敛研究"都在同时改变界面强度，结论无意义。

## 5. 粗化律诊断（§八）

用 m20 的 25 t block 数据（|H_1..4|² 与 bead 统计）：

* **|H_m|²**：t<150 的 0.01–0.3 → t>250 的 1–5，四个模**同向单向增长**（+126…+279% over 180 t），**到 t=300 仍无平台**；

⇒ **t≤300 内既不是清晰的经典幂律粗化、也未饱和到有限特征尺度**；更准确的描述是**持续的非平衡形貌演化（成珠—合并—再组织）**。

## 6. 最小判别实验：能否设计？（§九、§十）

* **不能**设计"纯分辨率"对照 case：按 §2/§3，不存在保持同一物理问题而只提高粒子数的参数化（`d/σ` 只能在 [1.10,1.20] 内变，且变动会同时改 λ_eff）。
* 因此本轮**不跑 R1/R2**（跑了也只能得到"改 φ 同时改 λ_eff"的混合结论，正是 Stage 7 已经证明无效的做法）。
* 若将来要实现真正的 resolution ladder，需要的 solver 变更（**本轮未实施，仅列清单**）：
  1. 引入独立的**离散参数**（如 `--particle-scale s = σ_disc/σ_phys`），使 WCA/Morse/壁面的**物理尺度用 σ_phys 表达、粒子间距用 s 表达**；
  2. `V0 → (√3/2)d²`（实际格胞面积），或把 `ρ_ref` 改成实际 n0，使 λ_eff 与离散化无关；
  3. `h_ρ` 固定为物理值（2.8 σ_phys），邻居截断相应放大（当前 2.6dx 会限制 h_ρ → 需同比例提高 dx 或改邻居策略）；
  4. 质量 m 与 k_BT 的约定同步（当前 m 硬编码 1）。

## 7. 最终回答（§十三）

**A. 当前"2 层膜"是否属于明显欠分辨状态？→ 是（对界面自由度而言）。**
膜厚只有 2 个粒子层、**外表面只有 1 层**，界面曲率/法向无法由粒子层内自由度表达；但**慢粗化的演化尺度（44–133 d）远大于离散尺度**，所以"欠分辨"不是慢粗化的直接来源，而是**模式幅值测量**的限制（已由 Method D 大部分解决）。

**B. 能否在不改变物理问题的情况下提高到 4–8 层？→ 不能。**
层数被 `rows=⌊(h−0.5σ)/dr⌋+1` 锁定，`dr` 由 `d` 由 `σ,φ` 决定，而 `φ<0.72` 是 WCA 密堆极限；把 σ 调小等于换相互作用模型。⇒ **`CURRENT MODEL HAS NO CLEAN RESOLUTION PARAMETER`**。

**C. Scheme E 是否支持分辨率缩放而无需重新标定？→ 目前不支持，需先修 `V0`。**
`c`（kernel 归一化）与 `h_ρ` 不随格距变化 ✓，但 `V0` 是固定常数 `1/0.88`，与膜的实际数密度不匹配 ⇒ `λ_eff = λ(V0 n0)²` 随 φ（即随离散化）变 ±11–17%。**必须先让 `V0` 等于实际格胞面积（或令 ρ_ref = n0），λ 才能原值传递。**

**D. 现有慢粗化更像 numerical under-resolution 还是 intrinsic coarse-grained dynamics？→ 更支持 intrinsic coarse-grained dynamics。**
依据：演化尺度 44–133× d、19× h_ρ，且低模功率集中于 m=1–4（无粒子尺度锁定特征）；T_kin 统计平稳而谱功率持续增长，是**模型自身内聚/热驱动的形貌演化**特征。

**E. 下一步：→ 先实现 resolution scaling，再做最小 convergence test；同时把主线从 RP 线性分析转向非平衡粗化/形貌演化。**
具体：① 先做 §6 的 4 项 solver 变更（轻量、可选，需批准）；② 变更后跑 2–3 个 case（coarse/medium/fine）做最小收敛判别；③ **在没有统计平稳基态之前，不再尝试 ω(k)**；④ 项目重心转为 **non-equilibrium coarsening / morphology evolution**（这与 Stage 10R 的结论一致，也符合 §十二 的界定：当前证据只支持"传统 stationary-base normal-mode test 在该工作点不适用"，**不支持**"RP mechanism does not exist"）。
