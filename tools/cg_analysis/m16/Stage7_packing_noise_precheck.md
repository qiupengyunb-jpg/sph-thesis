## 1. packing → 粒子间距关系（任务一）

代码事实（`cg_self_assembly_pri.cpp` L1279–1285，film 初态复用 `cluster_packing` 作面内堆积率）：

```
d  = σ·√( (π/4) / (0.5·√3·φ) )      # 三角晶格最近邻距
dr = (√3/2)·d                        # 径向层距
rows = floor((h_out − h_in)/dr) + 1  # 层数；h_in = 0.5σ
n    = max(3, floor(Lz/d + 0.5))     # 每层粒子数（z 方向）
```

|---|---|---|---|---|---|---|---|---|---|
| **0.63（当前基准）** | 1.1998 | 1.0391 | 2 | 2.0781 | 1.539 | 266 | 1.1998 | **+6.89%** | 可用 |
| **0.68** | 1.1548 | 1.0001 | 2 | 2.0003 | 1.500 | 278 | 1.1548 | **+2.89%** | 可用 |

| 0.72 | 1.1223 | 0.9720 | 2 | 1.9439 | 1.472 | 286 | 1.1223 | −0.01% | **solver 拒绝** |
| 0.75 | 1.0996 | 0.9523 | 2 | 1.9046 | 1.452 | 292 | 1.0996 | −2.03% | **solver 拒绝** |

**实测确认（solver 自身校验）**：

```
--cluster-packing=0.72 →
error: --cluster-packing must be in (0.05,0.72); 0.72 is the triangular lattice
       limit set by the WCA contact distance.
```

⇒ **0.72/0.75 不是"没试"，而是物理上不可达**（等于或超过 WCA 密堆极限）。
**可用 headroom 只有 φ∈(0.63, 0.72)，即初始面内拉伸从 +6.89% 最多降到 +1.40%**。

**结论（任务一）**：可以用 CLI 直接改初始膜间距 ✔；但**可用杠杆很小**（1.4–6.9%）。

注意两个易混量（必须写清）：
* `realised_thickness = rows·dr` 是**带厚**（从 h_in−dr/2 到 h_last+dr/2）；
* **外表面位置** `h_last = h_in + (rows−1)·dr` 才是模式分析关心的界面（φ=0.63 时 = **1.539σ**，不是 2.078σ）。

## 3. 判断标准（任务三，先声明）

本轮**预先声明**（不得事后调整）：

**若 packing 优化有效，应同时看到**
1. 弛豫后底噪（m=1..12 中位均值）**下降 ≥ 30%**；
2. A=0 对照的**伪增长率**下降（且该量在**帧距 ≤0.2 t** 下测得，见下）；
3. 弛豫后的 Fourier 背景（逐模）**整体下移**，而不是个别模互换大小。

**实测结果**：

| 判据 | 实测 | 通过 |
|---|---|---|
| 底噪下降 ≥30% | 0.0463 → 0.0564σ（**+22%**） | ❌ |
| 伪增长率下降 | 瞬态量，帧距 0.5 t 不足以定量（需 ≤0.2 t 重测） | ⚠ 未判定 |
| 逐模背景整体下移 | 低模上升、高模持平 | ❌ |

**⇒ 按预声明标准：packing 优化（在可用范围内）不足以降低 Fourier 底噪。**

### 因此问题更可能出在（按证据强度）

1. **粒子离散尺度**（最强证据）：2 层膜的外表面只有**一层**粒子，z 方向采样间隔 dz ≈ 2σ/m 的粒子间距 d ≈ 1.14–1.20σ（Lz=160、n=133–140）⇒ 外表面轮廓的**空间采样尺度 ≈1.2σ**，任何小于该尺度的结构都是**阿利亚斯噪声**。底噪量级 0.05–0.09σ 与"单个粒子偏离理想面"的量级一致。
2. **表面重建方法**：滑窗极大值重建在单层表面上的系统误差 ≈ 采样间隔 × |dh/dz|，对高模影响最大（m=5–8 底噪最大，正是 dz 的谐振区）。
3. **当前模型没有线性窗口**：T=0 下一次弛豫后冻结（Stage 6 已证），所以"线性增长窗口"在本设定下不存在——这与 packing 无关。

## 4. 是否值得进入重新 RP 单模扫描？

**结论：暂不值得按原方案（加大 packing）进入。**

理由：唯一可用的 packing 杠杆（0.63→0.70）只把初始弛豫幅度降了 44%，
**但没有降低 Fourier 底噪，也没有降低表面 ripple**；按预声明判据，判据 1 与 3 都不通过。

**建议的替代优先顺序（不改物理，只改观测/初态表征）**：

1. **提高轴向采样**（最直接）：同样 Lz=160 下把每层粒子数提高（即减小 d）**已被 WCA 极限封死**；
   因此应改成 **增加径向层数/提高 h** 或 **缩短 Lz**（同一 m 对应的 λ_z 变短 ⇒ 每波长采样点数增加）。
   例：Lz=160→80，m=5 的每波长粒子数从 32 增到 16... 方向相反；**正确做法是固定 λ_z 提高 d 的采样率**，
   即保持 Lz 但**降低 m 的上限**，只分析每波长 ≥8 个采样点的模（当前 m ≤ 12 时 λ_z ≥ 13.3σ，采样 ≈11 点/波长，
   已接近下限；m ≥ 5 的底噪最大正说明进入了采样极限）。
2. **换更鲁棒的外表面表征**（不改物理）：例如以**每 z 柱的粒子数加权质心 + 局部二次拟合**代替滑窗极大值，
   或对 h(z) 做**带限滤波**（只保留每波长 ≥10 采样点的模）后再评估。
3. 只有在 (1)/(2) 之后底噪仍不下降，才考虑"当前模型没有线性窗口"这一结论。

**如果仍要在 packing 方向做一次**：单点对照 φ=0.70 vs φ=0.63，**只跑 T=0、t≤50、帧距 ≤0.2 t**（用于定量伪增长率），
不要开 m 扫描。
