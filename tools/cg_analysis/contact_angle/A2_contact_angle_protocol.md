## 1. 接触角定义

### 1.1 主口径（等密度轮廓 + 圆帽几何）

```
H      = max(h) over the 0.5ρ_bulk contour  −  h_contact
l      = x-extent of the contour points with |h − 1.0σ| < 0.6σ
θ_iso  = 2·atan(2H / l)          [deg]
```

其中 `h = |y − Ly/2| − a` 是**粒子中心到壁面**的距离（`a = fibre_half_width`），
`h_contact = wall_re = 0.5σ` 是几何接触面（Morse-wall 阱底）。取液滴贴在**哪一侧**由轮廓自身位置决定（上下对称，取最大轮廓）。

几何依据：圆帽满足 `l = 2R sinθ`、`H = R(1−cosθ)`，消去 R 得 `tan(θ/2) = H/(l/2)`。
边界情形：θ→0（完全润湿，摊平）时 H→0、l 很大；θ→180°（完全不润湿）时 l→0，此时本式退化，程序会跳过该算例并把物理含义记为 θ ≥ 180°。

### 1.2 独立校核口径（自由界面圆拟合）

只取 **h > `--exclude-h`（默认 2σ）** 的轮廓点做最小二乘圆拟合，得圆心高度 `H_c`（相对接触面）与半径 `R_fit`，再按
`H = H_c + R_fit`、`l = 2·sqrt(R_fit² − H_c²)` 反解 θ_fit。

两套口径必须**同时**报告；若 |θ_iso − θ_fit| > 25° 视为该点几何不自洽，需在报告里标注（不得只报一个）。

## 2. 密度阈值与密度场

```
密度场   : 0.5σ 网格计数 / 格面积，再作 1σ 高斯平滑（x 方向周期、y 方向镜像）
ρ_bulk   : 以密度场 99.9 分位为参照，取 > 0.7·参照 的格子的中位数
界面     : 0.5·ρ_bulk 等密度轮廓（marching squares，取最长闭合段）
```

**不允许**改用"最外层粒子连线"定义界面、不允许改 ρ_bulk 的估计方式、不允许改动 0.5 这个系数。
（这条来自界面轮的直接教训：同一批算例换口径会让 θ 差 20° 以上，甚至跨过 90°。）

---

## 3. 拟合区域

* 接触宽度 l：只用 `|h − 1.0σ| < 0.6σ` 的轮廓点 —— 这是"贴着壁的第一个壳层上方"的位置，能稳定代表接触线；
* 圆拟合：只用 `h > 2σ` 的轮廓点（近壁 2σ 内的吸附壳层被排除）；
* 若可用点 < 8 个，该帧不计入（程序已实现）。

---

## 4. 平衡时间窗口

* 默认取 **t > 0.85·t_end** 的帧，等间隔抽到 ≤12 帧求平均（`--window` 可调，但必须在报告里写明实际取值）；
* 报告必须给出：`t_end`、窗口下界 `window_lo`、实际参与帧数 `n_frames`；
* **帧数 < 10 的结果标记为低置信**；
* 单条轨迹内的逐帧散布 `theta_iso_std` 必须一并给出（历史上它有 ±20–30°，是几何涨落而非误差）。

**A-2 生产算例的时间要求**：`t_end ≥ 4000`（与 A-1 同一尺度），`frames ≥ 200`（输出间隔 ≤20 个时间单位），
否则液滴在平壁上的铺展/吸附平衡未到、且窗口内帧数不足。

---

## 5. 重复初态的处理

1. **每个 ε_pf 至少 3 个独立初态**（不同 seed；建议同时用"正圆初态"与"椭圆初态"两种几何，检验是否与初态无关）；
2. 每个重复**独立**跑 `cg_contact_angle.py`（同一窗口比例、同一阈值），得到各自的 θ；
3. 汇报格式：

```
ε_pf | 每个重复的 θ_iso（列出）| 重复间平均 | 重复间标准差 | 每条轨迹的 theta_iso_std | θ_fit 平均
```

4. **头条不确定度用"重复间标准差"**（反映初态/轨迹差异），逐帧 std 只作为附注；
5. **禁止**把不同重复的帧混在一起做一次平均而不报重复间散布；
6. 若某个重复的 |θ_iso − θ_fit| > 25° 或 n_frames < 10，先剔除再统计，并在报告里注明剔除了几条。
