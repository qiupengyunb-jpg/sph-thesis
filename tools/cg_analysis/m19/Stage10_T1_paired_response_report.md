## 5. 最终回答（§十四）

**A. T=1 预平衡是否成功？→ 否。** 在 t ≤ 300 的 7 个候选中，无一满足预声明的 5 条统计稳态判据；低模谱（m=1–4）在 20 t 窗口内仍变化 0.22–5.6 倍，T_kin 也多次越出 [0.9,1.1]。

**B. common-random-number 配对是否成立？→ 未进入该阶段（未施加扰动）。**
结构上可行且已有先例：RNG 是 **counter-based**（`seed + OriginalID + timestep + component`，SplitMix64），**扰动分支不消耗任何随机数**；同一 seed、同一参数、同一 Phase-E 路径下，四个 case 的 Phase E 必然逐位一致（Stage 9 已在 T=0 下实测过注入前一帧 SHA256 完全相同）。若将来恢复本实验，这一步应作为第一道门槛按任务 §四 验证。

**C. m=2/3/4 是否出现可分离响应？→ 未测量**（前提不成立，按协议未做）。

**D. 各模属于增长/衰减/振荡/不可测？→ 不适用（未进入响应测量）**；本轮唯一可分类的对象是**背景本身**：在 t ≤ 300 内判为 **UNRESOLVED（非统计稳态）**。

**E. 是否值得进入 m=1..6 × 3 seeds dispersion test？→ 不值得。** 按 §十三，停止当前单模 RP 机制路线，把优先级转向：**空间分辨率/粒子层数** 或 **当前 coarse-grained dynamics 的物理适用性**评估（不再调 packing / temperature / A / Lz / detector）。
