# Stage 21 Phase 2 —— 两尺度核的数学设计（kernel design）

## 1. 目标与形式

保留 Scheme E 的泛函形式，只把配对核从单尺度换为**两尺度**：

```
F_E = (λ/2) V0² Σ_{i<j} J_ij · K̃_new(r_ij) · (ρ_i − ρ_j)²
K̃_new(r) = [ c_h W_h(r) − β · c_ξ W_ξ(r) ] / (1 − β)
W_h, W_ξ : 同一 Wendland C2 形式，支集分别为 h ≡ h_ρ 与 ξ（ξ > h）
c_h = 144/(5h²), c_ξ = 144/(5ξ²)      ← 各自都满足 ∫|u|² c W = 4
β ∈ [0, 1)                            ← β = 0 时**逐位退化**为 legacy
```

**归一化为什么这样选**：单项归一化给出 `∫|u|²K_h = ∫|u|²K_ξ = 4`，故组合的积分为 `4(1−β)`；
除以 `(1−β)` 后 `∫|u|²K̃_new = 4` ⇒ 与 legacy 相同的连续极限
`(1/2)∬(Δρ)²K̃ = ∫|∇ρ|²`，**λ 的物理含义（长波界面刚度）不变**。
⇒ **λ 无需重新标定**（这是本设计的关键优点）。

## 2. 必须保持的三条性质

| 要求 | 结论 | 理由 |
|---|---|---|
| **能量可计算** | ✅ | 与 legacy 同一泛函，仅核为两个 Wendland 的线性组合（各自 compact support、C²） |
| **力连续** | ✅ | Wendland C2 在 r=h、r=ξ 处 C²；线性组合仍 C² ⇒ `W'` 连续，且 `W'(0)=0` 无奇异；配对求和用**统一的支集 max(h,ξ)=ξ** |
| **对称（动量守恒）** | ✅ | `K̃_new` 径向 ⇒ 配对力反对称 `f_ij = −f_ji`（与 legacy 同一推导，未引入新支） |
| **能量—力一致（exact gradient）** | ✅ | legacy 的解析力推导对**任意径向核 K(r)** 成立（只用到 K 与 K'）；把 K→K̃_new 即得该能量的精确梯度 ⇒ energy–force FD 门槛可原样复用（`--sg-fd-check`） |

## 3. 傅里叶分析：能否给出有限 k 极值

对小幅密度调制 `ρ = ρ0 + a cos(kz)`：

```
(1/2)∬(Δρ)²K dA dA' = ∫|∇ρ|²dA · [1 + O(k²)]   ← 归一化保证零阶/二阶项
更完整的小 k 展开：  Ê(k) ≈ (λ/2) |a|² [ A k² + B k⁴ + O(k⁶) ] · Ω
A > 0（由 ∫|u|²K=4 保证；这是"短波稳定"支）
B 的符号由核的**非单调性**决定：当核存在**负的长程瓣**（β>0、ξ>h）时 B 可为负
⇒ k*² = −A/(2B) > 0 出现有限最速波长，量级 k* ~ 1/ξ  ⇒  λ* ≈ 2πξ
```

**与现有自由能的合成（Stage 20 的能量图）**：

```
总 k 空间行为 = Morse 吸引（k=0 最负，驱动粗化）
              + Scheme E(legacy)（+γk²，只压大 k）
              + 两尺度修正（−β·c_ξ 支 → 在有限 k 提供"低能通道"）
⇒ 只要 β 足够大，总 Ê(k) 在有限 k 出现**极小**，k=0 不再最低
```

**数值预期**（供实现后核对）：ξ = 2h_ρ = 5.6σ ⇒ k* ~ 1/5.6σ ⇒ **λ\* ≈ 30–40σ**，
与 Stage 13/18A/19 观测到的珠间距 **40–80σ** 同一量级 ✅ 说明该机制有希望落在可观测区间。

## 4. 与现有模型的兼容性

| 项 | 影响 |
|---|---|
| `λ`、`V0/ρ_ref`、`h_ρ` | **不变**（归一化设计保证 λ 含义不变） |
| Morse / WCA / wall / 恒温器 / 随机数 | **完全不动**（两尺度核只出现在 Scheme E 的配对项里） |
| legacy 路径 | `β=0`（或 `--interface-kernel=legacy`）⇒ 逐位不变（见 Phase 4-A） |
| 邻居搜索 | **需要 ξ ≤ 0.99·2.6·dx**；当前 dx≈1.2σ ⇒ **ξ ≤ ~3.0σ**。要测 ξ=5.6σ 必须粗化晶格或放大邻居截断（记为本设计的**首要工程约束**） |
| 诊断 | Scheme E 能量**必须新增**独立列（现有 `sg_energy` 是 Scheme A 口径，见 code map #5） |

## 5. Phase 3 实现要点（最小改动）

```
新增 CLI:      --interface-kernel=legacy|two_scale   (默认 legacy)
               --interface-xi=<ξ/σ>      --interface-beta=<β>
新增工厂:      inline Real SchemeKernelW(Real r)   // legacy: c_h W_h
                                                   // two_scale: [c_h W_h − β c_ξ W_ξ]/(1−β)
               inline Real SchemeKernelDW(Real r)
改 4 处调用:   ① CGSquareGradientConjugate 的 w
               ② CGSquareGradientDifferenceForce 的 w/dw
               ③ SGDifferenceConfigEnergy/Force 的 W/dW（FD 门槛用）
               ④ DumpForceSplit 的 w/dw
校验:          two_scale ⇒ 必须 axisymmetric + Scheme E + 0<β<1 + ξ>h_ρ + ξ ≤ 0.99·2.6·dx
不改:          λ、V0、h_ρ、Morse/WCA/wall、积分器、随机数
```

## 6. 风险与诚实标注

1. **"输入即答案"风险**：λ\* ≈ 2πξ ⇒ ξ 是输入。**接受前提**：ξ 由实验标定一次后冻结，模型的价值体现在 Phase 4 验收第 3/4 条（λ 随 R0/h 变化、且不是硬编码常数）。
2. **ξ 上限**：受邻居截断限制（见 §4），若必须用大 ξ 才能进入 40–80σ 区间，则需先解决截断（属另一层改动）。
3. **β 的物理可解释性**：β 表示"长程配对降能的比例"，属唯象参数；须在报告中明确它不是从实验直接测得的量。
4. **与 Stage 18A 数据质量提醒的关联**：任何后续参数图先在**干净的** case 集上做（P5≡P9 重复问题未解）。
