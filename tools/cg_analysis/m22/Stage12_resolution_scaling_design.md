**日期**：2026-09-23｜**性质**：设计 + 量纲推导（**未编码、未跑新算例**）

## 1. 六类长度尺度的分离（§三）

| 类别 | 当前以什么表达 | 是否可独立调节 |
|---|---|---|
| **物理长度尺度** | σ（=1）经 `m=σ=k_BT=1` 成为单位 | ✗（σ 就是单位本身） |
| **粒子/离散尺度** | `d = σ√((π/4)/(0.5√3φ))` | 只能经 φ 调 8%（φ<0.72 硬上限） |
| **相互作用长度** | WCA `2^{1/6}σ`、Morse `r_e=σ, α=3/σ, r_c=3σ`、wall `r0=0.5σ, r_c=2.5σ` | ✗（全部 ∝σ） |
| **kernel 平滑长度** | `h_ρ = 2.8σ`（并被邻居截断 `2.6dx` 约束） | 名义上可调，实际被截断与标定绑住 |
| **参考体积 / 粒子质量** | `V0 = 1/ρ_ref = 1.1364`（固定常数）、`m = 1`（硬编码） | ✗（V0 与真实格胞面积不符，见 §3） |
| **界面能归一化** | `λ = 12`（按 h_ρ=2.8 标定） | 名义上可调，实际与 V0·n0 绑住（见 §3） |

**关键结构事实**：σ 同时是"粒子尺寸"和"模型的长度单位"，因此**不存在一个独立于 σ 的物理尺子**去定义"同一物理几何"。这是本轮结论的根源。

## 2. refinement factor q 的定义尝试（§三）

想让 `q = 1,2,3…` 只改变每个 h 内的粒子层数，同时保持 physical R0 / h / Lz：

```
σ_disc = σ_ref / q            （更细的粒子）
R0, h, Lz 固定（以 σ_ref 计）  ⇒ R0/σ_disc = 5q, h/σ_disc = 2.08q, Lz/σ_disc = 160q
层数 rows ≈ h/dr_disc ∝ q     ⇒ 2 → 4 → 6 层 ✓
N ∝ q²                        ⇒ 266 → 1064 → 2394
```

**问题**：`R0/σ_disc`、`h/σ_disc`、`Lz/σ_disc` 这些**无量纲控制量全部随 q 变化**，所以这**不是**同一个无量纲问题。

| 无量纲量 | 当前值 | q 细化时 | 能否保持 |
|---|---|---|---|
| packing φ | 0.63 | 可保持（但见 Stage 11：φ 上限 0.72） | ✓（有限） |
| Morse 深/`k_BT` | 3.0 | 可保持（ε 不动） | ✓ |
| wall 深/`k_BT` | 13.0 | 可保持 | ✓ |

| ασ、r_e/σ、r_c/σ | 3、1、3 | 若相互作用长度随 σ_disc 缩放则**保持** | ✓ |
| **R0/σ_disc** | **5** | **5q** | **✗** |
| **h/σ_disc** | **2.08** | **2.08q** | **✗** |
| **Lz/σ_disc** | **160** | **160q** | **✗** |
| **涌现界面张力 `γ ∝ ε_pp/σ_disc`** | 1× | **q×** | **✗**（除非 ε_pp → ε_pp/q，那又破坏 ε/k_BT=3）|

⇒ 相互作用侧（Morse/WCA 的**形状**）可以按 σ_disc 同步缩放而保持无量纲形状；**但几何比值 R0/σ_disc、h/σ_disc 与涌现界面张力 γ 必然随 q 变**。而 R0/σ=5 只有 5 个 bead 直径——**没有尺度分离**可以支撑"更细粒子仍代表同一宏观问题"的假设。

## 4. Scheme E 的 resolution scaling 验算（§六、§七）——**这一侧是干净的**

```
F_E = (λ/2) V0² Σ_{i<j} J_ij K̃_ij (ρ_i−ρ_j)²        K̃ = c W，c = 144/(5h_ρ²)
```

逐项量纲（2D 的 (z,r) 平面）：
* `ρ_i = Σ_j W(r_ij) ≈ n0`（数密度，∝ 1/d²）；
* `V0` 若取**真实格胞面积** ⇒ `V0 = (√3/2)d²` ⇒ **`V0·n0 ≡ 1` 与 d 无关**；
* 配对求和 `Σ_{i<j} ≈ ½·A·n0²·∫K dA`；
* 代入：`F_E ≈ (λ/4)·(1/n0²)·A·n0²·π h_ρ² ⟨…⟩ = (λπ/4)·A·h_ρ²·⟨…⟩` ⇒ **与 d 无关**。

⇒ **只要 (a) `V0` 等于真实格胞面积、`ρ_ref = n0`，(b) `h_ρ` 保持物理值，(c) `c = 144/(5h_ρ²)` 不变**，
**`λ` 就无需随 q 缩放**，且 `F_E` 的单位物理长度界面能自动保持同一个 continuum 极限。

**对照当前实现**：`V0` 是固定常数 `1/0.88`，而膜的真实 n0=0.802σ⁻²（φ=0.63）⇒ `V0·n0 = 0.911` ⇒ `λ_eff = 9.96`（φ=0.70 时 12.3）。**这就是任何 convergence study 之前必须先修的那一项**（Stage 11 已记录）。

## 5. 相互作用侧为什么不能"只缩 σ"（§四、§九、§十）

若把 σ_disc → σ_ref/q 而**不改**相互作用：
* 粒子尺寸仍由 `2^{1/6}σ`（σ 是物理单位）决定 ⇒ **d < WCA 核 ⇒ 初始构型直接重叠**；"独立 dx"不是合法 refinement（§四 的警告成立）。
* 若把相互作用长度**一起按 σ_disc 缩**（WCA 核、Morse r_e/α/r_c、wall r0/r_c 全部 ×1/q），则：
  * 无量纲形状保持 ✓；
  * **但 ε 不变 ⇒ 每单位面积的凝聚能 ∝ ε·n0 ∝ q²，涌现界面张力 γ ∝ ε/σ_disc ∝ q ×q**；
  * 要让 γ 不变就必须 `ε_pp → ε_pp/q` ⇒ **`ε_pp/k_BT = 3` 被破坏**（而 T=1、k_BT=1 是冻结量）；
  * 反过来若保持 ε_pp 而接受 γ 增大，则界面项 λ 与 `ε_pp` 的相对标定失配（`λ=12` 是按旧 γ 标的）。
* **质量/温度约定**：粗粒子代表更小面积时，`m ∝ σ_disc²` 才能保持同一质量密度；但 `m` 当前**硬编码为 1**（`CGLangevinKick`/`CGLangevinOU`），且 `T_kin = ⟨v²⟩/(2k_BT)` 的质量归一也随之改变 ⇒ 要动 kick/OU/温度定义（§九 明确不希望"偷偷改惯性/热噪声强度"）。
* **时间尺度**：`τ_int = σ_disc√(m/ε)`；在上述缩放下 `dt` 需按 q 的幂次重推（§十），不能再沿用 0.0075；legacy 路径当然保持不动。

⇒ 相互作用侧**无法在保持同一宏观 constitutive model 的前提下细化**。

## 9. 最终回答（§二十）

**A. 是否真的存在物理一致的 resolution refinement mapping？→ 不存在（在保持 θ 与冻结参数的条件下）。**
根因：σ 同时是粒子尺寸与模型单位，reﬁnement 必然改变 `R0/σ`、`h/σ`、`Lz/σ` 与涌现 γ；而 R0/σ=5 无尺度分离，无法论证"更细粒子仍代表同一宏观问题"。

**B. 哪些量随 q 缩放？**（若强行做）
`σ_disc → σ/q`、`d → d/q`、层数 ∝ q、`N ∝ q²`、`V0 → V0/q²`（若取真实格胞面积）、`h_ρ/d → q·(h_ρ/d)`（邻居数 ∝ q²）、`dt` 需重推、`m ∝ 1/q²`（若要保质量密度，须改硬编码 m=1）；
而 `R0/σ`、`h/σ`、`Lz/σ`、涌现 γ **无法同时保持**。

**C. λ 是否需要重新缩放？→ Scheme E 侧不需要**（§4 推导：`V0·n0 ≡ 1` 时 `F_E` 与 d 无关，`λ` 原值传递；`c`、`h_ρ` 亦不变）；
**但前提是先修 `V0/ρ_ref`**（当前 `V0·n0 = 0.911` ⇒ `λ_eff = 9.96` 而非 12）——这是**必须做**的一项修正，本身与 refinement 无关。

**D. mass / dt / k_BT 如何处理？**
`k_BT` 与 `ε/k_BT` 的无量纲比值必须保持（否则换模型）；`m` 若要保持质量密度需 `∝1/q²`，但 `m=1` 当前硬编码在 kick/OU 与 `T_kin` 中 ⇒ 必须改三处并重新验证 FDT；`dt` 由最高刚度频率决定（∝√(ε/m)/σ），**不能沿用 0.0075**（legacy 路径当然保持不动）。这些都属于"模型层级改变"，需主线批准。

**E. R1/R2/R3 是否代表同一个物理问题？→ 否。** 三者 `R0/σ_disc` = 5/10/15、`h/σ_disc` = 2.1/4.2/6.2，涌现 γ 差 1/2/3 倍 ⇒ 无量纲控制量不同。

**F. 静态 interface energy 是否表现收敛？→ 未测试**；按 §7 的量纲预测**不会收敛**（γ ∝ q），故按 §十六 不应进入 dynamic convergence。

**G. 是否批准把 R1/R2/R3 交 PC2 做 dynamic convergence？→ 不批准。**
按 §十八 的正确结论：**当前 coarse-grained particle 是物理 bead（σ 是材料长度），不是可任意细化的数值粒子**。若主线仍需要收敛性/尺度分离，应改走**引入独立连续描述**的路线（例如显式表面张力参数化的 SPH/连续界面项，即当年 A-1 那条思路），而不是在 bead 模型内部做 refinement。

## 10. 风险与建议

| 风险 | 说明 |
|---|---|
| 强行 refine | 会同时改变 `R0/σ`、`h/σ` 与涌现 γ（q 倍），得到的是**另一个模型**，不能当收敛证据 |
| 只修 V0 不 refine | 这是**安全且必要**的：把 `V0` 改成真实格胞面积（或 `ρ_ref = n0`）后，`λ=12` 才名副其实（当前 φ=0.63 下真实 λ_eff=9.96）；建议作为**独立小改动**在下一次动 solver 时做，并做逐位回归 |
| 直接减 σ | 等于换相互作用模型，历史标定（λ=12、ε_pf=13、packing 0.63）全部失效 |

**建议下一步（二选一，交主线）**：
1. **接受 bead 模型**：不再做 resolution study，把项目重心放在**非平衡粗化 / 形貌演化**（与 Stage 10R/11 的结论一致）；
2. **走连续化路线**：引入可独立控制的界面张力/尺度参数（SPH 型或显式 γ），使"物理长度"与"离散长度"真正分离——这才是能定义 R1/R2/R3 的唯一途径。
